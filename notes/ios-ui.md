# iOS-inspired UI · 2026-09-09

这是一版现有 Web / PWA 的视觉优化，不是 SwiftUI 原生应用，也不涉及 App Store 打包或服务器迁移。

## 设计依据

使用用户提供的 https://github.com/emilkowalski/skills 中 `apple-design` 与 `emil-design-eng`：系统字体、重量与间距共同建立层级、分组邻近性、即时按压反馈、克制的功能性色彩、减少动效/透明度支持。未引入 UI 框架或新的动画依赖。

## 视觉规则

- 系统字体优先；标题 28px，任务正文 14px，习惯/行为正文 13px。保持列表密度，不统一放大所有字。
- 浅灰分组背景 + 白色内嵌列表；灰色细分隔线。蓝色只承担主操作、当前选择和链接的角色。
- 目标身份色继续保留；不再给所有已评分行为整圈蓝色边框，避免与真正选中的行为混淆。
- 四个主视图共用分段导航，仍位于目标/主线入口下方。保留现有左右滑切换与方向反馈。
- 手机单列，桌面任务/日程双列。分组、关键结果直达、批量操作、评分规则均未改动。
- 时间框保持恒定边框宽度，只在编辑时强调，避免有值即“永久聚焦”。
- 手机弹层贴底并照顾安全区；桌面弹层限制内容宽度。触控设备表单文字至少 16px，避免 iOS 自动放大输入框。
- 轻透明只用于悬浮工具栏，不给内容叠加装饰性玻璃；支持 reduced-motion / reduced-transparency。

## 回归检查

- `npm run build`：类型检查与生产构建通过（项目原有 SWC 版本警告仍在）。
- 浏览器 390×844、320×740 手机尺寸与 1280×900 桌面尺寸检查；修复窄屏输入框挤出模板按钮的问题。
- 新增无固定时间任务、改期直接输入 1930、保存、撤回恢复；桌面双栏仍正常。
- 习惯新增、打卡及正反馈；目标/关键结果分组保留。
- 创建目标与关键结果、加入行为、展开评分与流程入口、加入习惯后归属保留。
- 计时中改名与停止记账正常。

浏览器尺寸检查不等同于真机 Safari 测试；键盘弹出、触觉反馈及真实手势还需用户在手机上体验。测试数据仅在独立 localhost 端口创建，未写入线上用户数据。
